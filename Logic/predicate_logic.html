Predicate Logic (First-Order Logic)

Logic GATE DA 📖 ~18 min read

Predicate Logic (also called First-Order Logic or FOL) extends Propositional Logic by introducing objects, predicates, and quantifiers. It is far more expressive — capable of representing complex real-world knowledge that propositional logic cannot handle.

Why Predicate Logic? Propositional Logic can say "Socrates is mortal" as a single atom P. But it cannot express the general rule "All humans are mortal." Predicate Logic can: ∀x Human(x) → Mortal(x) — and then derive Mortal(Socrates) automatically.

1. Propositional vs Predicate Logic

FeaturePropositional LogicPredicate Logic (FOL)
Basic unit Proposition (P, Q, R) Predicate applied to objects: Likes(Alice, Bob)
Objects ✗ None ✓ Constants, Variables, Functions
Quantifiers ✗ None ✓ ∀ (for all), ∃ (there exists)
Expressiveness Low High — describes relationships between objects
Example P = "It is raining" Raining(London) or ∀x City(x) → HasWeather(x)
Decidability Decidable Semi-decidable

2. Building Blocks of FOL

2.1 Terms — What Things Exist

Terms refer to objects in the world. There are three kinds:

TypeDefinitionExamples
Constant A specific named object Alice, Bob, 5, London
Variable A placeholder for any object x, y, z (lowercase)
Function Maps objects to objects FatherOf(x), SquareOf(3)

2.2 Predicates — Properties and Relations

A predicate is a function that takes objects as arguments and returns True or False. It describes a property of an object or a relation between objects.

PredicateMeaningExample
Human(x) x is a human Human(Socrates) = True
Mortal(x) x is mortal Mortal(Socrates) = True
Likes(x, y) x likes y Likes(Alice, Bob) = True
Greater(x, y) x is greater than y Greater(5, 3) = True

The number of arguments a predicate takes is called its arity. Human(x) has arity 1. Likes(x, y) has arity 2.

2.3 Connectives

Same logical connectives as Propositional Logic:

  • ¬ (NOT), ∧ (AND), ∨ (OR)
  • → (Implication), ↔ (Biconditional)

2.4 Equality

FOL includes the special predicate = for equality: x = y means x and y refer to the same object.

FatherOf(Alice) = Bob    (Bob is Alice's father)

3. Quantifiers

Quantifiers are the most powerful feature of Predicate Logic — they allow statements about all objects or some objects in the domain.

3.1 Universal Quantifier ∀ (For All)

∀x P(x)    "For all x, P(x) is true"

The statement is true if P(x) holds for every object in the domain.

Examples:

  ∀x Human(x) → Mortal(x)
  "Every human is mortal"

  ∀x (Cat(x) → Animal(x))
  "All cats are animals"

  ∀x ∀y Likes(x,y) → Likes(y,x)
  "If x likes y then y likes x" (symmetry)

3.2 Existential Quantifier ∃ (There Exists)

∃x P(x)    "There exists an x such that P(x) is true"

The statement is true if P(x) holds for at least one object.

Examples:

  ∃x Human(x) ∧ Smart(x)
  "There exists a human who is smart"

  ∃x Cat(x) ∧ BlackCat(x)
  "There exists a black cat"

  ∃x ∃y Likes(x,y)
  "Someone likes someone"

3.3 Scope of Quantifiers

The scope of a quantifier is the formula it applies to. Parentheses control scope. 

  ∀x (Human(x) → Mortal(x))   ← x is bound by ∀
  ∃y Likes(Alice, y)           ← y is bound by ∃

  Free variable: appears in formula but NOT bound by any quantifier
  Bound variable: appears under a quantifier

3.4 Quantifier Interactions

The order of quantifiers matters when mixing ∀ and ∃:

FormulaMeaning
∀x ∃y Likes(x,y) Everyone likes someone (possibly different people)
∃y ∀x Likes(x,y) There is someone that everyone likes (same person)
Key Rule: ∀x ∃y ≠ ∃y ∀x — swapping quantifiers changes meaning. The second formula is stronger (implies the first but not vice versa).

3.5 Negating Quantifiers

De Morgan's Laws apply to quantifiers:

¬∀x P(x)  ≡  ∃x ¬P(x) ¬∃x P(x)  ≡  ∀x ¬P(x)

In English:

  • ¬∀x P(x) = "Not all x satisfy P" = "Some x does not satisfy P" = ∃x ¬P(x)
  • ¬∃x P(x) = "No x satisfies P" = "All x do not satisfy P" = ∀x ¬P(x)

Example:

  ¬∀x Human(x) → Mortal(x)
  ≡ ∃x ¬(Human(x) → Mortal(x))
  ≡ ∃x Human(x) ∧ ¬Mortal(x)
  "There exists an immortal human"

4. Well-Formed Formulas (WFF)

A sentence in FOL must be a well-formed formula (WFF) with no free variables — every variable must be bound by a quantifier.

Atomic Sentences

The simplest sentences — a predicate applied to terms:

Human(Socrates)    Likes(Alice, Bob)    Greater(x, 0)

Complex Sentences

Built from atomic sentences using connectives and quantifiers:

  Human(Socrates) ∧ Philosopher(Socrates)
  ∀x Human(x) → Mortal(x)
  ∃x (Student(x) ∧ Smart(x))
  ∀x ∀y (Loves(x,y) → Loves(y,x))

5. Interpretation

An interpretation specifies the meaning of FOL sentences by providing:

ComponentMeaning
Domain D The set of all objects that exist in this world
Constants Each constant maps to a specific object in D
Predicates Each predicate maps to a set of tuples from D
Functions Each function maps tuples of D to elements of D

Example

  Domain: D = {Alice, Bob, Charlie}

  Interpretation:
  Human(Alice) = True
  Human(Bob)   = True
  Human(Charlie) = False

  Likes = {(Alice, Bob), (Bob, Alice)}  ← pairs where Likes is True

  Evaluate: ∀x Human(x) → Mortal(x)
  → Need to check for every x in D
  → True if whenever Human(x) is True, Mortal(x) is also True

Satisfiability and Validity in FOL

TermMeaning
Satisfiable True in at least one interpretation
Valid (Tautology) True in ALL interpretations
Unsatisfiable False in ALL interpretations

6. Unification

Unification is the process of finding a substitution (called a unifier) that makes two logical expressions identical. It is the core operation used in FOL inference — especially in Resolution.

Substitution

A substitution θ is a mapping from variables to terms:

θ = {x/Alice, y/Bob}    (replace x with Alice, y with Bob)

Unification Algorithm

UNIFY(p, q) returns a substitution θ such that p·θ = q·θ (applying θ to both makes them identical), or FAIL if no such θ exists.

Unification Examples

Expression 1Expression 2Unifier θ
Knows(John, x) Knows(John, Jane) {x/Jane}
Knows(John, x) Knows(y, Bill) {y/John, x/Bill}
Knows(John, x) Knows(x, Elizabeth) FAIL (x cannot be both John and Elizabeth)
Knows(John, x) Knows(John, Mother(x)) FAIL (occur check — x cannot equal Mother(x))
Likes(x, x) Likes(Alice, Alice) {x/Alice}

Most General Unifier (MGU)

The Most General Unifier (MGU) is the substitution that makes the minimal number of commitments — it is the most general solution. 

  UNIFY(Knows(John, x), Knows(John, y))

  Possible unifiers:
  θ₁ = {x/Jane, y/Jane}  ← too specific
  θ₂ = {x/y}             ← MGU (most general — just says x and y are same)

  MGU = {x/y}

Occur Check

Before substituting x with a term t, check that x does not appear inside t. If x appears in t → FAIL (would create infinite structure).

UNIFY(x, f(x)) → FAIL    (x appears inside f(x))

Why Unification Matters

Unification enables Generalized Modus Ponens in FOL:

∀x Human(x) → Mortal(x)
Human(Socrates)
─────────────────────────────────────
Unify: {x/Socrates}
∴ Mortal(Socrates)

7. Inference in FOL

FOL uses the same inference rules as Propositional Logic, extended with rules for quantifiers.

7.1 Universal Instantiation (UI)

From a universal statement, we can derive a specific instance by substituting any ground term for the variable.

∀x P(x)
─────────────────
∴ P(c)    for any constant c

Example:

  ∀x Human(x) → Mortal(x)
  ──────────────────────────────────
  Human(Socrates) → Mortal(Socrates)   {x/Socrates}
  Human(Alice)    → Mortal(Alice)      {x/Alice}

7.2 Existential Instantiation (EI)

From an existential statement, introduce a new constant (Skolem constant) to name the object that exists.

∃x P(x)
─────────────────
∴ P(k)    where k is a new constant (Skolem constant)

Example:

  ∃x (Human(x) ∧ Smart(x))
  ──────────────────────────────────
  Human(k) ∧ Smart(k)    where k is a new Skolem constant

7.3 Generalized Modus Ponens

Combines Modus Ponens with Unification:

∀x P(x) → Q(x)  ,  P(c)
─────────────────────────────────
∴ Q(c)    with unifier {x/c}

8. English to FOL Translation

Translating English sentences to FOL is a key GATE skill.

Domain: people and things. Predicates: Human(x), Mortal(x), Likes(x,y), Smart(x), Student(x), Teacher(x)

1. "All humans are mortal."

∀x Human(x) → Mortal(x)

Pattern: "All A are B" → ∀x A(x) → B(x)

2. "Some humans are smart."

∃x Human(x) ∧ Smart(x)

Pattern: "Some A are B" → ∃x A(x) ∧ B(x)

3. "No human is immortal."

∀x Human(x) → ¬Immortal(x)

Or equivalently: ¬∃x Human(x) ∧ Immortal(x)

4. "Every student likes some teacher."

∀x Student(x) → ∃y Teacher(y) ∧ Likes(x,y)

Every student (∀x) has some teacher (∃y) that they like.

5. "There is a teacher that every student likes."

∃y Teacher(y) ∧ ∀x Student(x) → Likes(x,y)

One specific teacher (∃y) is liked by ALL students (∀x). Stronger than sentence 4!

6. "Only students are smart."

∀x Smart(x) → Student(x)

Pattern: "Only A are B" → ∀x B(x) → A(x)  (note direction flip!)

7. "Alice and Bob both like each other."

Likes(Alice, Bob) ∧ Likes(Bob, Alice)

8. "Everyone likes themselves."

∀x Likes(x, x)

Common Translation Patterns

English PatternFOL Pattern
"All A are B"∀x A(x) → B(x)
"Some A are B"∃x A(x) ∧ B(x)
"No A are B"∀x A(x) → ¬B(x)
"Only A are B"∀x B(x) → A(x)
"There is an A that is B"∃x A(x) ∧ B(x)
"Every A has some B"∀x A(x) → ∃y B(y) ∧ R(x,y)
"There is a B for every A"∃y B(y) ∧ ∀x A(x) → R(x,y)

GATE Tips

  • ∀x uses → (implication). ∃x uses ∧ (AND). This is the most common mistake — never write ∀x A(x) ∧ B(x) for "All A are B".
  • ¬∀x P(x) ≡ ∃x ¬P(x) and ¬∃x P(x) ≡ ∀x ¬P(x) — quantifier negation rules.
  • Order matters: ∀x ∃y ≠ ∃y ∀x — always read left to right.
  • Unification finds substitution θ to make two expressions identical. MGU = most general unifier.
  • Occur check: UNIFY(x, f(x)) = FAIL — x cannot be substituted with a term containing x.
  • Universal Instantiation: ∀x P(x) → P(c) for any constant c.
  • Existential Instantiation: ∃x P(x) → P(k) where k is a new Skolem constant.
  • "Only A are B" → ∀x B(x) → A(x) — note the direction is flipped from "All A are B".
  • FOL is semi-decidable — if a sentence is valid, a proof will eventually be found; if invalid, the search may never terminate.
  • Free variable = not bound by any quantifier. A valid FOL sentence has no free variables.
📝  Practice Questions

Q1 Which FOL formula correctly translates "All cats are animals"?

  1. ∃x Cat(x) ∧ Animal(x)
  2. ∀x Cat(x) ∧ Animal(x)
  3. ∀x Cat(x) → Animal(x)
  4. ∃x Cat(x) → Animal(x)
Show Answer

Answer: C — ∀x Cat(x) → Animal(x)

"All A are B" always uses ∀ with →. Using ∧ with ∀ would mean "everything is both a cat and an animal" — wrong.

Q2 Which FOL formula correctly translates "Some students are smart"?

  1. ∀x Student(x) → Smart(x)
  2. ∃x Student(x) → Smart(x)
  3. ∃x Student(x) ∧ Smart(x)
  4. ∀x Student(x) ∧ Smart(x)
Show Answer

Answer: C — ∃x Student(x) ∧ Smart(x)

"Some A are B" always uses ∃ with ∧. There exists an x who is both a student AND smart.

Q3 What is ¬∀x P(x) equivalent to?

  1. ∀x ¬P(x)
  2. ∃x ¬P(x)
  3. ¬∃x P(x)
  4. ∃x P(x)
Show Answer

Answer: B — ∃x ¬P(x)

By quantifier De Morgan: ¬∀x P(x) ≡ ∃x ¬P(x). "Not all x satisfy P" = "Some x does not satisfy P".

Q4 UNIFY(Knows(John, x), Knows(y, Alice)) = ?

  1. FAIL
  2. {x/Alice, y/John}
  3. {x/John, y/Alice}
  4. {x/y}
Show Answer

Answer: B — {x/Alice, y/John}

To make Knows(John, x) = Knows(y, Alice): set y=John (first arg) and x=Alice (second arg).

Q5 What is the difference between ∀x ∃y Likes(x,y) and ∃y ∀x Likes(x,y)?

  1. They mean the same thing
  2. First: everyone likes someone. Second: there is one person everyone likes
  3. First: someone likes everyone. Second: everyone likes someone
  4. Both are invalid FOL formulas
Show Answer

Answer: B

∀x ∃y: for each x, there exists a y (can be different y for each x). ∃y ∀x: one fixed y that all x like. The second is much stronger.

Q6 "Only teachers can grade exams." Translates to:

  1. ∀x Teacher(x) → CanGrade(x)
  2. ∃x Teacher(x) ∧ CanGrade(x)
  3. ∀x CanGrade(x) → Teacher(x)
  4. ∀x Teacher(x) ∧ CanGrade(x)
Show Answer

Answer: C — ∀x CanGrade(x) → Teacher(x)

"Only A can B" means "if you can B, you must be A" — the direction is flipped. If x can grade, then x must be a teacher.

Q7 Universal Instantiation allows us to derive:

  1. ∀x P(x) from P(c)
  2. P(c) from ∀x P(x) for any constant c
  3. ∃x P(x) from ∀x P(x)
  4. ¬P(c) from ∀x ¬P(x)
Show Answer

Answer: B — P(c) from ∀x P(x)

UI lets us substitute any constant for the universally quantified variable to get a specific instance.

Q8 UNIFY(f(x), f(g(x))) gives:

  1. {x/g(x)}
  2. {x/f(x)}
  3. FAIL — occur check violation
  4. {g(x)/x}
Show Answer

Answer: C — FAIL due to occur check

To unify f(x) with f(g(x)) we would need x = g(x). But x appears inside g(x) — this violates the occur check and would create an infinite structure.

Q9 Which of the following is TRUE about FOL?

  1. FOL is decidable — all valid sentences can be proved or disproved
  2. FOL is semi-decidable — valid sentences can be proved but invalid ones may loop forever
  3. FOL is less expressive than Propositional Logic
  4. FOL cannot express relationships between objects
Show Answer

Answer: B — Semi-decidable

FOL is semi-decidable: if a sentence is valid (a tautology), a complete inference procedure will eventually find a proof. But if it is not valid, the search may run forever.

Q10 "Every student has exactly one advisor." Translates to:

  1. ∀x Student(x) → ∃y Advisor(y,x)
  2. ∀x Student(x) → ∃y Advisor(y,x) ∧ ∀z Advisor(z,x) → z=y
  3. ∃y ∀x Student(x) → Advisor(y,x)
  4. ∀x ∀y Student(x) ∧ Advisor(y,x)
Show Answer

Answer: B

"Exactly one" means: there exists an advisor (∃y) AND any other advisor must be the same person (∀z ... z=y). "At least one" + "at most one" = exactly one.
