Logic in Artificial Intelligence

Logic GATE DA 📖 Topic Overview

Logic is the foundation of Artificial Intelligence. It provides a formal language for representing knowledge and a set of rules for deriving new knowledge through reasoning. AI agents use logic to make decisions, prove theorems, and understand the world.

Why Logic in AI? Humans reason using logic every day — "If it is raining, I will carry an umbrella." AI systems need a formal way to represent such knowledge and reason with it automatically. Logic provides exactly that — a precise, unambiguous language for knowledge representation.

What is Logic?

Logic is the study of valid reasoning. It defines:

  • Syntax — What sentences are legal / well-formed
  • Semantics — What sentences mean (true or false in the world)
  • Inference — How to derive new true sentences from existing ones

The Core Goal

Given a set of known facts (Knowledge Base), logic allows an AI agent to automatically derive new conclusions that must be true — without explicitly being told them. 

  Knowledge Base (KB):
  ├── "It is raining"              → P = True
  └── "If it rains, roads are wet" → P → Q = True

  Derived automatically:
  └── "Roads are wet"              → Q = True  ✓

Knowledge Base & Inference

A Knowledge Base (KB) is a collection of sentences in a formal language. An AI agent uses the KB to answer queries by logical inference.

Two Operations on a KB

OperationMeaning
TELL Add a new sentence to the KB (store a fact or rule)
ASK Query the KB — derive whether something is true

Entailment

The KB entails a sentence α (written KB |= α) if α is true in every possible world where KB is true.

Entailment vs Implication: Implication (P → Q) is a sentence inside the logic. Entailment (KB |= α) is a statement about truth across all possible worlds — a stronger guarantee.

Inference

Inference is the process of deriving sentences from the KB. A good inference algorithm is:

  • Sound — only derives sentences that are actually entailed (no wrong conclusions)
  • Complete — derives every sentence that is entailed (misses nothing)

GATE Tips

  • Propositional Logic is simpler and decidable — always terminates.
  • Predicate Logic (FOL) is more expressive but only semi-decidable.
  • A Sound inference system never derives false conclusions.
  • A Complete inference system can derive everything that is entailed.
  • Entailment (|=) is about truth in all possible worlds — stronger than implication.
  • Syntax = structure. Semantics = meaning. Inference = reasoning.
  • Every consistent heuristic is admissible — same pattern: stronger condition implies weaker.
  • In GATE, most logic questions test truth tables, equivalence laws, and inference rules.
