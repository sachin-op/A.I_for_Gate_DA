Introduction to Propositional Logic

Logic GATE DA 📖 ~18 min read

Propositional Logic is a branch of logic that deals with propositions and their relationships using logical connectives. A proposition is a declarative statement that is either True or False, but not both.

Understanding Implication (P → Q)

Implication is a logical statement of the form:

P → Q    read as: "If P, then Q"

Terminology

  • P — Antecedent (the condition / premise)
  • Q — Consequent (the result / conclusion)

Key Idea

The implication P → Q is false only when P = True and Q = False. In every other case it is true.

1. Logical Equivalence

Two propositions are logically equivalent (P ≡ Q) if they have identical truth tables.

P → Q  ≡  ¬P ∨ Q

This means: "If P then Q" is logically equivalent to "Not P OR Q".

Intuition

  • If P is true, then Q must be true
  • If P is false, the implication automatically becomes true

Example

Let P: "It is raining"  ·  Q: "The ground is wet"

P → Q = "If it is raining, then the ground is wet."

Important Logical Equivalence Laws

1. De Morgan's Laws

¬(P ∧ Q) ≡ ¬P ∨ ¬Q ¬(P ∨ Q) ≡ ¬P ∧ ¬Q

Example:

¬(A ∧ B) ≡ ¬A ∨ ¬B

2. Contrapositive Law

P → Q ≡ ¬Q → ¬P

Example: "If it rains then roads are wet"

R → W ≡ ¬W → ¬R

3. Distributive Laws

P ∨ (Q ∧ R) ≡ (P ∨ Q) ∧ (P ∨ R) P ∧ (Q ∨ R) ≡ (P ∧ Q) ∨ (P ∧ R)

4. Double Negation Law

¬(¬P) ≡ P

Combined Example — Simplify ¬(P → Q)

Step 1: Remove implication

P → Q ≡ ¬P ∨ Q

Step 2: Apply negation

¬(¬P ∨ Q)

Step 3: Apply De Morgan's Law

¬(¬P) ∧ ¬Q

Step 4: Apply Double Negation

∴   ¬(P → Q) ≡ P ∧ ¬Q

1.1 Inference Rules

Inference rules allow us to derive new truths without constructing full truth tables. They are fundamental tools in logical reasoning and AI theorem proving.

1. Modus Ponens

If an implication is true and its premise is true, then the conclusion must also be true.

P → Q  ,  P
─────────────
∴  Q

Example: P: It is raining  ·  Q: The ground is wet

P → Q , P  ⇒  Q

If it is raining and we know "rain → wet ground", therefore the ground is wet.

2. Resolution (The AI Rule)

Resolution is widely used in automated theorem proving and logic-based AI systems.

P ∨ Q  ,  ¬P ∨ R
───────────────────
∴  Q ∨ R

Logic Behind Resolution:

  • If P is true → from ¬P ∨ R, R must be true.
  • If P is false → from P ∨ Q, Q must be true.

Thus in either case, Q ∨ R is true.

1.2 Translation Examples

Converting English sentences into propositional logic — very important for GATE problems.

Let: p = "Alice is smart"  ·  q = "Alice is honest"

1. "Alice is not smart but honest."

⇒ ¬p ∧ q

"but" in logic behaves like AND (∧). So: not smart AND honest.

2. "If Alice is smart, then she is not honest."

⇒ p → ¬q

Whenever p is true, q must be false. Only p=T, q=T violates this.

3. "Either Alice is smart, or she is not smart but honest."

⇒ p ∨ (¬p ∧ q)

4. "Alice is either smart or honest, but not honest if smart."

⇒ (p ∨ q) ∧ (p → ¬q)

5. "Smart is necessary and sufficient for honest."

⇒ (p → q) ∧ (q → p)  ≡  p ↔ q

Necessary vs. Sufficient

TypeFormMeaning
Sufficientp → qp guarantees q
Necessaryq → pq requires p

2. Types of Propositions

1. Tautology (Valid)

Always True for all possible truth values.

P ∨ ¬P  ≡  T    (Law of Excluded Middle)

2. Contradiction (Unsatisfiable)

Always False for all possible truth values.

P ∧ ¬P  ≡  F    (Law of Contradiction)

3. Contingency

Neither always true nor always false — True in some cases, False in others.

P → Q    (depends on P and Q)

2.1 Satisfiability vs. Validity

Satisfiable

A proposition is Satisfiable if there is at least one row in the truth table where the result is True.

  • Tautologies → always Satisfiable
  • Contingencies → Satisfiable (True in some rows)
  • Contradictions → Not Satisfiable

5. Concept of a Model

In propositional logic (used in AI), we separate two important concepts:

  • Syntax → The logical sentences we write (like P, Q, P → Q).
  • Semantics → What those sentences actually mean in the real world.

A model is a possible world where every proposition has a fixed truth value.

"In this imagined world, which statements are true and which are false?"

Example

Model 1: P = True, Q = False   → raining, not Tuesday
Model 2: P = False, Q = True   → Tuesday, not raining

Exponential Growth of Models

With n propositions → 2n possible models.

  • 1 proposition → 2 models
  • 2 propositions → 4 models
  • 3 propositions → 8 models

If α is true in all possible models, then β must also be true in those models.

📝  Practice Questions

Q1 Which is logically equivalent to ¬(p ∧ q)?

  1. ¬p ∧ ¬q
  2. ¬p ∨ ¬q
  3. p ∨ q
  4. ¬(p → q)
Show Answer

Answer: B — ¬p ∨ ¬q

By De Morgan's Law: ¬(p ∧ q) ≡ ¬p ∨ ¬q

Q2 If p → q is True and p is False, then q must be:

  1. True
  2. False
  3. Cannot be determined
  4. Always False
Show Answer

Answer: C — Cannot be determined

If p is False, implication is automatically True regardless of q.

Q3 Which of the following is a contradiction?

  1. p ∨ ¬p
  2. p ∧ ¬p
  3. p → p
  4. ¬(p ∧ ¬p)
Show Answer

Answer: B — p ∧ ¬p

Requires P to be both True and False simultaneously — impossible.

Q4 The negation of (p → q) is:

  1. ¬p ∨ q
  2. p ∧ ¬q
  3. ¬q ∨ p
  4. ¬p ∧ q
Show Answer

Answer: B — p ∧ ¬q

Q5 Given p → q and q → r, which must be true?

  1. p → r
  2. r → p
  3. p ∧ r
  4. q → p
Show Answer

Answer: A — p → r

Hypothetical Syllogism / Transitivity of implication.

Q6 Which is equivalent to (p → q) ∧ (p → r)?

  1. p → (q ∧ r)
  2. (p ∧ q) → r
  3. (p ∨ q) → r
  4. p → (q ∨ r)
Show Answer

Answer: A — p → (q ∧ r)

Q7 Which is equivalent to (p → r) ∧ (q → r)?

  1. (p ∧ q) → r
  2. (p ∨ q) → r
  3. p → (q ∧ r)
  4. ¬p ∧ ¬q
Show Answer

Answer: B — (p ∨ q) → r

Q8 Assertion: p ∨ ¬p is a tautology.   Reason: Either p is True or p is False.

  1. Both true and R explains A
  2. Both true but R does not explain A
  3. A true, R false
  4. A false, R true
Show Answer

Answer: A

Q9 Which expression is logically equivalent to p ∨ q?

  1. ¬p → q
  2. p → q
  3. ¬q → p
  4. p ∧ q
Show Answer

Answer: A — ¬p → q

Q10 Which is satisfiable but NOT a tautology?

  1. p ∨ ¬p
  2. p ∧ ¬p
  3. p → q
  4. ¬(p ∨ ¬p)
Show Answer

Answer: C — p → q

True in some cases, False in others → Contingency → Satisfiable but not Tautology.
