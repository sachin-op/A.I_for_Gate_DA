Representation — Bayesian Networks

Reasoning Under Uncertainty GATE DA 📖 ~15 min read

A Bayesian Network (also called Belief Network or Bayes Net) is a compact, graphical representation of a joint probability distribution. It exploits conditional independence to encode the full joint distribution using far fewer parameters than a complete joint table.

Core Idea: Instead of storing P(X₁, X₂, ..., Xₙ) — which needs 2n entries — a Bayesian Network stores only P(Xᵢ | Parents(Xᵢ)) for each variable. Each variable only depends on a small number of parents, making the representation exponentially more compact.

1. What is a Bayesian Network?

A Bayesian Network consists of two components:

ComponentDescription
Graph Structure A Directed Acyclic Graph (DAG) where nodes = random variables and directed edges = direct causal relationships
CPTs A Conditional Probability Table for each node — gives P(Xᵢ | Parents(Xᵢ))

Properties of the Graph

  • Directed — edges have direction (cause → effect)
  • Acyclic — no cycles allowed (a variable cannot be its own ancestor)
  • Nodes — each node is a random variable (discrete or continuous)
  • Edges — X → Y means X directly influences Y
  • No edge between X and Y means they are conditionally independent given their parents

2. Classic Example — Burglary Network

This is the standard textbook Bayesian Network example. A burglar alarm can be triggered by a burglary or an earthquake. If the alarm goes off, John or Mary may call.

Joint Distribution Factorization

Using the Markov Condition, the full joint factorizes as:

P(B,E,A,J,M) = P(B) × P(E) × P(A|B,E) × P(J|A) × P(M|A)

Instead of 25 − 1 = 31 numbers for the full joint table, we only need the CPT entries — a much smaller number.

3. Conditional Probability Tables (CPTs)

Each node in a Bayesian Network has a Conditional Probability Table (CPT) that specifies P(Xᵢ = true | combinations of parent values).

4. Computing from a Bayesian Network

4.1 Computing a Specific Joint Probability

To compute P(B=T, E=F, A=T, J=T, M=T) using the factorization: 

  P(B=T, E=F, A=T, J=T, M=T)
  = P(B=T) × P(E=F) × P(A=T|B=T,E=F) × P(J=T|A=T) × P(M=T|A=T)
  = 0.001  × 0.998  × 0.94            × 0.90        × 0.70
  = 0.001 × 0.998 × 0.94 × 0.90 × 0.70
  ≈ 0.000592

4.2 Computing a Marginal Probability

To find P(B=T) (probability of burglary), we sum over all combinations of other variables:

P(B=T) = Σ_{E,A,J,M} P(B=T, E, A, J, M)

This is called marginalization — summing out unwanted variables.

4.3 Computing a Conditional (Posterior) Probability

To find P(B=T | J=T, M=T) — burglary given both called:

P(B=T | J=T, M=T) = P(B=T, J=T, M=T) / P(J=T, M=T)

This is the main query in a Bayesian Network — compute posterior probability of hidden variables given observed evidence. Done using Exact Inference (Variable Elimination) or Approximate Inference (Sampling).

5. Why Bayesian Networks are Compact

If each node has at most k parents, the total number of CPT entries across all n nodes is at most:

n × 2k

Compare this to the full joint table which needs 2n entries:

Key Insight: A Bayesian Network is an exponentially more compact representation than the full joint distribution, thanks to conditional independence. This is what makes probabilistic reasoning feasible in large domains.

6. How to Construct a Bayesian Network

  1. Identify variables — what are the relevant random variables in the domain?
  2. Order variables — typically causes before effects (topological order)
  3. Add nodes — one node per variable
  4. Add edges — for each variable, identify its direct causes and add edges from each cause to the variable
  5. Fill CPTs — for each node, specify P(Xᵢ | combinations of parent values)

Important Rule

When constructing the network, add edges only for direct causal relationships. Do not add an edge from X to Z if the effect of X on Z is entirely mediated through another variable Y (i.e. X → Y → Z). Adding unnecessary edges makes the CPTs larger without improving accuracy.

Causal vs Non-Causal: Bayesian Networks can technically represent any conditional independence structure — not just causal ones. But causal networks are easier to construct correctly and are more interpretable.

GATE Tips

  • A Bayesian Network = DAG + CPTs. Both parts must be understood.
  • Factorization formula: P(X₁...Xₙ) = Π P(Xᵢ | Parents(Xᵢ)) — memorize this.
  • Root nodes (no parents) → simple prior probability P(X).
  • CPT size for a node with k parents = 2k rows.
  • Total parameters in BN ≤ n × 2k vs 2n for full joint.
  • In GATE numerical questions — apply the factorization, multiply the relevant CPT values.
  • P(query | evidence) = P(query, evidence) / P(evidence) — always normalize.
  • Absent edge X → Y means X ⊥ Y | Parents(Y) — no edge = conditional independence.
  • The Markov Blanket of a node = its parents + children + co-parents (other parents of its children). A node is independent of all others given its Markov Blanket.
📝  Practice Questions

Q1 A Bayesian Network is a:

  1. Directed Cyclic Graph with probability tables
  2. Directed Acyclic Graph with Conditional Probability Tables
  3. Undirected graph with joint probability tables
  4. Binary tree with marginal probabilities
Show Answer

Answer: B — DAG with CPTs

A Bayesian Network is a Directed Acyclic Graph where each node has a CPT specifying P(Xᵢ | Parents(Xᵢ)).

Q2 The joint distribution factorization in a Bayesian Network is:

  1. P(X₁,...,Xₙ) = Σ P(Xᵢ | Parents(Xᵢ))
  2. P(X₁,...,Xₙ) = Π P(Xᵢ | Parents(Xᵢ))
  3. P(X₁,...,Xₙ) = Π P(Xᵢ)
  4. P(X₁,...,Xₙ) = P(X₁) × P(X₂|X₁) × P(X₃|X₁,X₂) × ...
Show Answer

Answer: B — Product of P(Xᵢ | Parents(Xᵢ))

The Markov Condition allows the joint to factorize as a product of local conditional distributions.

Q3 A node with 3 boolean parents has a CPT with how many rows?

  1. 3
  2. 6
  3. 8
  4. 16
Show Answer

Answer: C — 8 rows

With k = 3 boolean parents, CPT has 23 = 8 rows — one for each combination of parent values.

Q4 In the burglary network, what does the absence of a direct edge from Burglary to JohnCalls mean?

  1. Burglary never causes John to call
  2. John calling is independent of burglary given alarm state
  3. John calling depends directly on burglary
  4. The network is incorrect
Show Answer

Answer: B — J ⊥ B | A

No direct edge means conditional independence. John calls only based on alarm — once alarm state is known, burglary gives no additional information.

Q5 For a BN with n=20 variables and max k=3 parents per node, how many parameters are needed (approximately)?

  1. 1,048,576 (full joint)
  2. 160
  3. 60
  4. 20
Show Answer

Answer: B — 160

n × 2k = 20 × 23 = 20 × 8 = 160. Compare to 220 = 1,048,576 for the full joint.

Q6 Using the burglary network CPTs, P(A=T | B=T, E=F) = ?

  1. 0.95
  2. 0.94
  3. 0.29
  4. 0.001
Show Answer

Answer: B — 0.94

From the CPT: when B=T and E=F, P(A=T | B=T, E=F) = 0.94.

Q7 The Markov Blanket of a node X consists of:

  1. Only X's parents
  2. Only X's children
  3. X's parents, children, and co-parents (other parents of X's children)
  4. All nodes in the network
Show Answer

Answer: C — Parents + Children + Co-parents

X is conditionally independent of ALL other nodes given its Markov Blanket.

Q8 Why must a Bayesian Network be acyclic (DAG)?

  1. To make the graph look neat
  2. To ensure the joint factorization is valid — cycles would cause circular dependencies
  3. To reduce the number of edges
  4. Because cyclic graphs cannot store probabilities
Show Answer

Answer: B — Prevents circular dependencies

Cycles would mean X causes Y and Y causes X — making the factorization P(X₁...Xₙ) = Π P(Xᵢ|Parents) undefined. Acyclicity ensures a valid topological ordering.
