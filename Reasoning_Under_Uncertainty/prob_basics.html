Probability Basics

Reasoning Under Uncertainty GATE DA 📖 ~15 min read

In the real world, an AI agent rarely has complete and certain knowledge. Probability provides a formal framework for reasoning under uncertainty — allowing an agent to represent degrees of belief and make rational decisions even when facts are incomplete or noisy.

Why Probability in AI? Logic says a statement is either True or False. But in the real world, "It will rain tomorrow" is neither definitely true nor false — it has a probability. AI agents must handle this uncertainty to act intelligently.

Basic Terminology

TermMeaningExample
Experiment A process with uncertain outcomes Rolling a die
Sample Space (Ω) Set of all possible outcomes {1, 2, 3, 4, 5, 6}
Event A subset of the sample space Getting an even number = {2, 4, 6}
Probability P(A) Likelihood of event A occurring P(even) = 3/6 = 0.5

Axioms of Probability

  • 0 ≤ P(A) ≤ 1 — probability is always between 0 and 1
  • P(Ω) = 1 — something in the sample space always happens
  • P(A ∪ B) = P(A) + P(B) — if A and B are mutually exclusive

Useful Probability Rules

RuleFormula
Complement Rule P(¬A) = 1 − P(A)
Addition Rule P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
Multiplication Rule P(A ∩ B) = P(A) × P(B|A)

1. Random Variables

A Random Variable (RV) is a variable whose value is determined by the outcome of a random experiment. It maps outcomes from the sample space to numerical values.

Definition: A random variable X is a function X : Ω → ℝ that assigns a real number to each outcome in the sample space.

1.1 Types of Random Variables

Discrete RVContinuous RV
Definition Takes countable values Takes any value in a range
Examples Number of heads in 10 flips, die outcome Height, weight, temperature
Distribution Probability Mass Function (PMF) Probability Density Function (PDF)
P(X = x) P(X = x) can be non-zero P(X = x) = 0 for any specific x
Sum/Integral Σ P(X = x) = 1 ∫ f(x) dx = 1

1.2 Probability Mass Function (PMF)

For a discrete random variable X, the PMF gives the probability that X takes each specific value.

P(X = x) = probability that X equals x

Example — Fair Die:

x123456
P(X = x) 1/61/61/61/61/61/6

All probabilities sum to 1: 6 × (1/6) = 1 ✓

1.3 Joint Probability

The joint probability P(X = x, Y = y) is the probability that random variable X takes value x AND Y takes value y simultaneously.

P(X = x, Y = y) = P(X = x ∩ Y = y)

1.4 Marginal Probability

The marginal probability of X is obtained by summing the joint probability over all values of Y.

P(X = x) = Σy P(X = x, Y = y)

Example:

X \ YY=0Y=1P(X)
X=00.10.30.4
X=10.20.40.6
P(Y)0.30.71.0

P(X=0) = 0.1 + 0.3 = 0.4  ·  P(Y=1) = 0.3 + 0.4 = 0.7

1.5 Expected Value (Mean)

The expected value E[X] is the weighted average of all possible values of X, weighted by their probabilities.

E[X] = Σ x · P(X = x)    (discrete)

Example — Fair Die:

E[X] = 1×(1/6) + 2×(1/6) + 3×(1/6) + 4×(1/6) + 5×(1/6) + 6×(1/6) = 21/6 = 3.5

1.6 Variance

The variance Var(X) measures how spread out the values of X are around the expected value.

Var(X) = E[X²] − (E[X])² Std Dev = σ = √Var(X)

2. Conditional Probability

Conditional Probability P(A|B) is the probability of event A occurring given that event B has already occurred. It updates our belief about A based on new information B.

Formula

P(A|B) = P(A ∩ B) / P(B)    where P(B) > 0

Intuition

When B occurs, the sample space shrinks to only those outcomes where B is true. We then ask: within this reduced space, what fraction also satisfies A?

Example

A bag has 4 red balls and 6 blue balls. Two balls are drawn without replacement. 

  P(2nd is red | 1st is red) = ?

  P(1st red) = 4/10
  P(1st red AND 2nd red) = (4/10) × (3/9) = 12/90

  P(2nd red | 1st red) = P(both red) / P(1st red)
                       = (12/90) / (4/10)
                       = (12/90) × (10/4)
                       = 120/360
                       = 1/3  ✓

2.1 Independence

Two events A and B are independent if knowing B occurred gives no information about A.

A and B are independent ⟺ P(A|B) = P(A) Equivalently: P(A ∩ B) = P(A) × P(B)

Example: Flipping a fair coin twice — the result of the first flip does not affect the second flip.

P(H on flip 2 | H on flip 1) = P(H on flip 2) = 1/2 ✓

2.2 Chain Rule of Probability

The chain rule extends conditional probability to multiple events:

P(A ∩ B) = P(A|B) × P(B) P(A ∩ B ∩ C) = P(A|B ∩ C) × P(B|C) × P(C)

2.3 Law of Total Probability

If B₁, B₂, ..., Bₙ are mutually exclusive and exhaustive events (they partition the sample space), then:

P(A) = Σ P(A|Bᵢ) × P(Bᵢ)

Example:

  Factory has 2 machines:
  Machine 1 makes 60% of items, defect rate 2%
  Machine 2 makes 40% of items, defect rate 5%

  P(defect) = P(defect|M1)×P(M1) + P(defect|M2)×P(M2)
            = 0.02×0.60 + 0.05×0.40
            = 0.012 + 0.020
            = 0.032 = 3.2%

3. Bayes' Theorem

Bayes' Theorem allows us to update our beliefs about a hypothesis when we observe new evidence. It is the foundation of probabilistic reasoning in AI.

Formula

P(H|E) = [ P(E|H) × P(H) ] / P(E)

Components

TermNameMeaning
P(H|E) Posterior Updated probability of H after seeing evidence E
P(E|H) Likelihood Probability of seeing evidence E if H is true
P(H) Prior Initial probability of H before seeing evidence
P(E) Marginal / Evidence Total probability of evidence E (normalizing constant)

How to Remember

Posterior ∝ Likelihood × Prior

(∝ means "proportional to" — P(E) is just a normalizing constant to make probabilities sum to 1)

Derivation

Bayes' Theorem follows directly from the definition of conditional probability:

  P(H|E) = P(H ∩ E) / P(E)          ... (definition of conditional prob)
  P(E|H) = P(H ∩ E) / P(H)          ... (definition of conditional prob)

  From the second: P(H ∩ E) = P(E|H) × P(H)

  Substituting into the first:
  P(H|E) = P(E|H) × P(H) / P(E)     ✓

Classic Example — Medical Diagnosis

  Disease D affects 1% of population
  Test T: 99% accurate if disease present    P(T+|D) = 0.99
          5% false positive rate             P(T+|¬D) = 0.05

  Question: If test is positive, what is P(D|T+)?

  Prior:     P(D) = 0.01,  P(¬D) = 0.99

  P(T+) = P(T+|D)×P(D) + P(T+|¬D)×P(¬D)   ← Law of Total Probability
        = 0.99×0.01 + 0.05×0.99
        = 0.0099 + 0.0495
        = 0.0594

  P(D|T+) = P(T+|D) × P(D) / P(T+)
           = 0.99 × 0.01 / 0.0594
           = 0.0099 / 0.0594
           ≈ 0.1667 ≈ 16.67%
Key Insight: Even with a 99% accurate test, a positive result only means ~17% chance of actually having the disease. This is because the disease is rare (1% prior). Bayes' Theorem correctly accounts for this — this is why it is so powerful in medical AI, spam filters, and diagnostic systems.

Example 2 — Spam Filter

  P(Spam) = 0.4         (40% of emails are spam)
  P(¬Spam) = 0.6

  Word "FREE" appears in:
  P(FREE|Spam) = 0.9    (90% of spam contains "FREE")
  P(FREE|¬Spam) = 0.1   (10% of non-spam contains "FREE")

  P(FREE) = 0.9×0.4 + 0.1×0.6 = 0.36 + 0.06 = 0.42

  P(Spam|FREE) = P(FREE|Spam) × P(Spam) / P(FREE)
               = 0.9 × 0.4 / 0.42
               = 0.36 / 0.42
               ≈ 0.857 = 85.7%

If an email contains "FREE" → 85.7% probability it is spam.

3.1 Bayes' Theorem with Multiple Hypotheses

When there are multiple mutually exclusive hypotheses H₁, H₂, ..., Hₙ:

P(Hᵢ|E) = P(E|Hᵢ) × P(Hᵢ) / Σⱼ P(E|Hⱼ) × P(Hⱼ)

The denominator Σⱼ P(E|Hⱼ) × P(Hⱼ) is just P(E) expanded using the Law of Total Probability.

Key Formulas Summary

FormulaName
P(A ∪ B) = P(A) + P(B) − P(A ∩ B)Addition Rule
P(¬A) = 1 − P(A)Complement Rule
P(A|B) = P(A ∩ B) / P(B)Conditional Probability
P(A ∩ B) = P(A|B) × P(B)Chain Rule
P(A ∩ B) = P(A) × P(B)Independence
P(A) = Σ P(A|Bᵢ) × P(Bᵢ)Total Probability
P(H|E) = P(E|H) × P(H) / P(E)Bayes' Theorem
E[X] = Σ x · P(X=x)Expected Value
Var(X) = E[X²] − (E[X])²Variance

GATE Tips

  • P(A|B) = P(A ∩ B) / P(B) — memorize this definition first.
  • Independent events: P(A ∩ B) = P(A) × P(B). Always verify this before assuming independence.
  • Law of Total Probability is used to find P(E) in Bayes' Theorem.
  • Bayes' Theorem: Posterior = (Likelihood × Prior) / Evidence.
  • In Bayes problems — always identify Prior, Likelihood, and Evidence first before computing.
  • Marginal probability = sum joint probabilities over all values of the other variable.
  • P(A|B) ≠ P(B|A) — a very common mistake. Bayes' Theorem tells you how to switch them.
  • In medical diagnosis problems — low base rate (prior) dramatically reduces posterior even with accurate tests.
  • Variance formula: Var(X) = E[X²] − (E[X])² — faster than computing directly.
  • Conditional probability reduces sample space — think of it as zooming into the region where B is true.
📝  Practice Questions

Q1 Which formula defines conditional probability P(A|B)?

  1. P(A) × P(B)
  2. P(A ∩ B) / P(B)
  3. P(A) + P(B) − P(A ∩ B)
  4. P(B ∩ A) × P(A)
Show Answer

Answer: B — P(A ∩ B) / P(B)

Conditional probability P(A|B) is the joint probability P(A ∩ B) divided by the probability of the condition P(B).

Q2 Two events A and B are independent if and only if:

  1. P(A ∩ B) = 0
  2. P(A|B) = P(B)
  3. P(A ∩ B) = P(A) × P(B)
  4. P(A ∪ B) = 1
Show Answer

Answer: C — P(A ∩ B) = P(A) × P(B)

Independence means knowing B gives no information about A. This is equivalent to P(A ∩ B) = P(A) × P(B).

Q3 In Bayes' Theorem P(H|E) = P(E|H)×P(H)/P(E), what is P(H) called?

  1. Likelihood
  2. Posterior
  3. Prior
  4. Evidence
Show Answer

Answer: C — Prior

P(H) is the prior probability — our belief about H before seeing evidence E.

Q4 A bag has 3 red and 7 blue balls. P(red on 2nd draw | red on 1st draw) without replacement is:

  1. 3/10
  2. 2/9
  3. 3/9
  4. 2/10
Show Answer

Answer: B — 2/9

After drawing 1 red, there are 2 red balls left out of 9 remaining. P = 2/9.

Q5 P(A ∪ B) when A and B are mutually exclusive is:

  1. P(A) × P(B)
  2. P(A) + P(B) − P(A ∩ B)
  3. P(A) + P(B)
  4. 1 − P(A) − P(B)
Show Answer

Answer: C — P(A) + P(B)

Mutually exclusive means P(A ∩ B) = 0, so P(A ∪ B) = P(A) + P(B) − 0 = P(A) + P(B).

Q6 Disease affects 2% of people. Test is 95% accurate (sensitivity) and has 3% false positive rate. Given a positive test, P(Disease|Positive) ≈ ?

  1. 95%
  2. 2%
  3. 39%
  4. 50%
Show Answer

Answer: C — approximately 39%

P(+) = 0.95×0.02 + 0.03×0.98 = 0.019 + 0.0294 = 0.0484
P(D|+) = 0.95×0.02 / 0.0484 = 0.019/0.0484 ≈ 0.393 ≈ 39%

Q7 The expected value of a fair die (faces 1–6) is:

  1. 3
  2. 3.5
  3. 4
  4. 2.5
Show Answer

Answer: B — 3.5

E[X] = (1+2+3+4+5+6)/6 = 21/6 = 3.5

Q8 P(A|B) = P(B|A) is true when:

  1. Always
  2. Never
  3. When P(A) = P(B)
  4. When A and B are mutually exclusive
Show Answer

Answer: C — When P(A) = P(B)

From Bayes: P(A|B) = P(B|A)×P(A)/P(B). So P(A|B) = P(B|A) only when P(A) = P(B).

Q9 The Law of Total Probability states:

  1. P(A) = P(A|B) + P(A|¬B)
  2. P(A) = Σ P(A|Bᵢ) × P(Bᵢ) for a partition {Bᵢ}
  3. P(A) = P(A ∩ B) / P(B)
  4. P(A) = P(B|A) × P(A)
Show Answer

Answer: B — P(A) = Σ P(A|Bᵢ) × P(Bᵢ)

When B₁, B₂,...,Bₙ partition the sample space, the total probability of A is the weighted sum of conditional probabilities.

Q10 Which of the following is the correct formula for Variance?

  1. E[X] − (E[X²])
  2. E[X²] − (E[X])²
  3. (E[X])² − E[X²]
  4. E[X]²
Show Answer

Answer: B — E[X²] − (E[X])²

Var(X) = E[X²] − (E[X])². This is the most efficient formula to compute variance.
