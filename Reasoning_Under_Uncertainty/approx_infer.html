Approximate Inference

Reasoning Under Uncertainty GATE DA 📖 ~15 min read

Exact inference in large Bayesian Networks can be computationally intractable — especially in densely connected networks where treewidth is high. Approximate Inference uses sampling (Monte Carlo) methods to estimate probabilities rather than computing them exactly. The estimates improve as more samples are drawn.

Trade-off: Approximate inference gives up guaranteed exact answers in exchange for scalability. Given enough samples, the estimates converge to the true probabilities. For large networks where exact inference is impossible, this is the only practical option.

Why Sampling Works

By generating many random samples from the joint distribution and counting how often certain events occur, we estimate probabilities empirically. With N samples:

P(X = x) ≈ (number of samples where X = x) / N

As N → ∞, the estimate converges to the true probability.

1. Prior Sampling

Prior Sampling is the simplest sampling method. It generates samples from the prior distribution — ignoring any evidence — by sampling each variable in topological order according to its CPT.

Algorithm

  1. Order all variables in topological order (parents before children)
  2. For each variable Xᵢ (in order):
    • Look up P(Xᵢ | parents already sampled)
    • Sample a value for Xᵢ from this distribution
  3. Record the complete assignment as one sample
  4. Repeat N times to get N samples
  5. Estimate P(query) by counting relevant samples

Example — Burglary Network

  Network: B → A → J

  Topological order: B, A, J

  Sample generation:
  ─────────────────────────────────────
  Step 1: Sample B from P(B)
          P(B=T) = 0.001 → B = F  (most likely)

  Step 2: Sample A from P(A | B=F)
          P(A=T | B=F) = 0.001 → A = F

  Step 3: Sample J from P(J | A=F)
          P(J=T | A=F) = 0.05 → J = F

  One sample: (B=F, A=F, J=F)
  ─────────────────────────────────────
  After 1000 samples, count how many have J=T to estimate P(J=T).

Estimating Probabilities

P(X = x) ≈ count(X = x) / N

Properties

PropertyValueExplanation
Handles evidence? ✗ No Ignores evidence — samples from prior only
Consistent? ✓ Yes Converges to true probability as N → ∞
Efficiency Poor with rare evidence Most samples will be rejected when evidence is unlikely
Best for Unconditional queries Estimating P(X) without any evidence

2. Rejection Sampling

Rejection Sampling extends Prior Sampling to handle evidence. It generates samples as before, but rejects any sample that is inconsistent with the observed evidence.

Algorithm

  1. Generate a sample using Prior Sampling
  2. Check if the sample is consistent with evidence e
    • If consistent → keep the sample
    • If inconsistent → reject the sample (discard it)
  3. Repeat until N consistent samples are collected
  4. Estimate P(query | e) using only the kept samples

Example

  Query: P(B=T | J=T)   [given John called]

  Generate samples, keep only those where J=T:

  Sample 1: B=F, A=F, J=F  → REJECT (J≠T)
  Sample 2: B=F, A=T, J=T  → KEEP
  Sample 3: B=T, A=T, J=T  → KEEP
  Sample 4: B=F, A=F, J=F  → REJECT
  Sample 5: B=F, A=T, J=T  → KEEP

  Kept samples: {(B=F,A=T,J=T), (B=T,A=T,J=T), (B=F,A=T,J=T)}
  P(B=T | J=T) ≈ 1/3 ≈ 0.33

  (This is a rough estimate — need many more samples for accuracy)

Properties

PropertyValueExplanation
Handles evidence? ✓ Yes Conditions on evidence by rejecting inconsistent samples
Consistent? ✓ Yes Converges to true posterior as N → ∞
Efficiency Poor for rare evidence If P(e) is small, most samples are rejected — very wasteful
Rejection rate 1 − P(e) High rejection rate when evidence is unlikely
Problem: If evidence e is rare (e.g. P(J=T, M=T) ≈ 0.003), then 99.7% of samples are rejected — extremely wasteful. Likelihood Weighting fixes this.

3. Likelihood Weighting

Likelihood Weighting fixes the inefficiency of Rejection Sampling by never rejecting samples. Instead, it fixes evidence variables to their observed values and assigns each sample a weight based on the probability of the evidence.

Algorithm

  1. Initialize weight w = 1.0
  2. For each variable in topological order:
    • If it is an evidence variable: → fix it to observed value, multiply w by P(evidence_value | parents)
    • If it is a non-evidence variable: → sample normally from P(Xᵢ | parents)
  3. Record sample with its weight w
  4. Repeat N times
  5. Estimate P(query | e) using weighted counts

Estimate Formula

P(X = x | e) ≈ Σ{w_s : X_s = x} / Σ w_s

Sum of weights where X = x, divided by total weight of all samples.

Example

  Query: P(B | J=T)   Network: B → A → J

  Sample generation:
  ─────────────────────────────────────────────────────
  Step 1: Sample B (non-evidence) from P(B)
          B = F  (sampled)
          w = 1.0

  Step 2: Sample A (non-evidence) from P(A|B=F)
          A = T  (sampled)
          w = 1.0

  Step 3: J is EVIDENCE (J=T)
          Fix J = T
          w = w × P(J=T | A=T) = 1.0 × 0.90 = 0.90

  Sample: (B=F, A=T, J=T),  weight = 0.90
  ─────────────────────────────────────────────────────

  After many samples:
  P(B=T | J=T) ≈ Σ(w where B=T) / Σ(all w)

Properties

PropertyValueExplanation
Handles evidence? ✓ Yes Evidence variables fixed — no rejection
Rejects samples? ✗ Never All samples kept with a weight — no waste
Consistent? ✓ Yes Converges to true posterior
Efficiency Better than Rejection Sampling No samples wasted — all contribute with their weight
Best for Most practical cases Handles rare evidence well
Limitation of Likelihood Weighting: When evidence is far downstream in the network, the weights of samples that reach it may be very low — causing high variance. Gibbs Sampling handles this better.

4. Gibbs Sampling

Gibbs Sampling is a Markov Chain Monte Carlo (MCMC) method. Instead of generating each sample independently, it starts with a random assignment and makes small changes — sampling one variable at a time while keeping all others fixed.

Algorithm

  1. Fix evidence variables to their observed values
  2. Initialize all non-evidence variables randomly
  3. Repeat many times:
    • Pick a non-evidence variable Xᵢ at random
    • Sample a new value for Xᵢ from P(Xᵢ | all other variables)
    • Record the current full assignment as a sample
  4. Estimate P(query | e) by counting over all recorded samples

The Key Simplification

Instead of conditioning on ALL other variables (which would be expensive), Gibbs uses the Markov Blanket — a node only depends on its parents, children, and co-parents:

P(Xᵢ | all others) = P(Xᵢ | MarkovBlanket(Xᵢ))

Example

  Network: B → A → J, Query: P(B | J=T)
  Evidence: J = T (fixed)

  Initial state: B = F, A = T  (random)

  Iteration 1:
    Sample B from P(B | A=T) ∝ P(B) × P(A=T|B)
    P(B=T | A=T) ∝ 0.001 × 0.94 = 0.00094
    P(B=F | A=T) ∝ 0.999 × 0.001 = 0.000999
    After normalizing → B = F  (sampled)
    Record: (B=F, A=T)

  Iteration 2:
    Sample A from P(A | B=F, J=T)
    ∝ P(A|B=F) × P(J=T|A)
    P(A=T|B=F,J=T) ∝ 0.001 × 0.90 = 0.0009
    P(A=F|B=F,J=T) ∝ 0.999 × 0.05 = 0.04995
    After normalizing → A = F  (sampled)
    Record: (B=F, A=F)

  After many iterations, count B=T to estimate P(B=T|J=T)

Properties

PropertyValueExplanation
Handles evidence? ✓ Yes Evidence variables kept fixed throughout
Sample independence? ✗ No Each sample depends on the previous one (Markov Chain)
Consistent? ✓ Yes Converges to true posterior under mild conditions
Burn-in needed? ✓ Yes Early samples (before convergence) are discarded
Best for Large networks with complex evidence Works well when LW weights are too low

GATE Tips

  • Prior Sampling — samples from prior, no evidence handling, each variable sampled in topological order.
  • Rejection Sampling — generates prior samples, rejects those inconsistent with evidence. Wasteful when evidence is rare.
  • Likelihood Weighting — fixes evidence variables, weights each sample by P(evidence | parents). Never rejects.
  • LW weight formula: w = Π P(eᵢ | Parents(eᵢ)) for all evidence variables eᵢ.
  • Gibbs Sampling — MCMC method. Updates one variable at a time using Markov Blanket. Samples are NOT independent.
  • All four methods are consistent — converge to true probability as N → ∞.
  • Ordering from simplest to most practical: Prior → Rejection → Likelihood Weighting → Gibbs.
  • Gibbs requires a burn-in period — discard early samples before the chain mixes.
  • P(X=x | e) ≈ weighted_count(X=x) / total_weight — use this for LW estimate.
  • In GATE questions — identify which method is being described and trace through the algorithm step by step.
📝  Practice Questions

Q1 Which sampling method NEVER rejects samples?

  1. Prior Sampling
  2. Rejection Sampling
  3. Likelihood Weighting
  4. None — all methods reject sometimes
Show Answer

Answer: C — Likelihood Weighting

LW fixes evidence variables and weights samples instead of rejecting them. All samples are kept.

Q2 In Rejection Sampling, a sample is rejected when:

  1. The weight of the sample is too low
  2. The sample is inconsistent with observed evidence
  3. A hidden variable gets an unlikely value
  4. The query variable is False
Show Answer

Answer: B — Inconsistent with evidence

If an evidence variable's sampled value doesn't match the observed value, the whole sample is rejected.

Q3 In Likelihood Weighting, the weight of a sample is:

  1. Always 1.0
  2. Product of P(query variable values)
  3. Product of P(evidence value | parents) for all evidence variables
  4. 1 / number of samples
Show Answer

Answer: C — Product of P(evidence | parents)

For each evidence variable eᵢ set to value vᵢ, multiply the weight by P(Eᵢ=vᵢ | Parents(Eᵢ)).

Q4 Gibbs Sampling differs from the other methods because:

  1. It only works on polytree networks
  2. Consecutive samples are NOT independent — it is a Markov Chain method
  3. It never converges to the true probability
  4. It cannot handle evidence variables
Show Answer

Answer: B — Markov Chain, samples are dependent

In Gibbs Sampling, each state is generated by modifying the previous state — samples are correlated, unlike the other three methods.

Q5 Which method is BEST when the evidence event is very rare (low probability)?

  1. Prior Sampling
  2. Rejection Sampling
  3. Likelihood Weighting
  4. All methods perform equally
Show Answer

Answer: C — Likelihood Weighting

With rare evidence, Rejection Sampling wastes almost all samples. LW fixes evidence and weights — none are wasted.

Q6 All four approximate inference methods share which property?

  1. They produce independent samples
  2. They are consistent — converge to true probability as N → ∞
  3. They handle evidence by rejection
  4. They give exact answers for small networks
Show Answer

Answer: B — Consistent

All four sampling methods are consistent estimators — they converge to the correct probability with enough samples.

Q7 Prior Sampling samples variables in which order?

  1. Random order
  2. Reverse topological order
  3. Topological order — parents before children
  4. Alphabetical order
Show Answer

Answer: C — Topological order

We must sample parents before children so that CPT values P(Xᵢ | parents) can be used for sampling.

Q8 What is the "burn-in period" in Gibbs Sampling?

  1. Time to initialize CPTs
  2. The first N samples discarded before the chain has mixed properly
  3. Time to compute Markov Blankets
  4. The final samples used for the estimate
Show Answer

Answer: B — Early samples discarded before mixing

Before the Markov Chain reaches its stationary distribution, early samples may not represent the true posterior. These are discarded as "burn-in".
