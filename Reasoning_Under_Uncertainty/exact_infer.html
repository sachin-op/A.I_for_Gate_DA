Exact Inference

Reasoning Under Uncertainty GATE DA 📖 ~15 min read

Exact Inference in a Bayesian Network computes the exact posterior probability of query variables given observed evidence. The most important exact inference algorithm is Variable Elimination.

The Core Problem: Given a Bayesian Network and some observed evidence e, compute P(X | e) — the probability distribution over query variable X given what we have observed.

Example: Given the burglary network and evidence that John called (J=T) and Mary called (M=T), compute P(Burglary | J=T, M=T).

1. Inference by Enumeration

The simplest exact inference method — sum over all possible values of hidden variables.

General Formula

P(X | e) = α × Σhidden P(X, e, hidden)

Where α is a normalizing constant to make probabilities sum to 1.

Steps

  1. Fix the query variable X and evidence variables e
  2. Sum the joint probability over all combinations of hidden variables
  3. Normalize so probabilities sum to 1

Example — Simple 3-node network

  Network:  B → A → J   (simplified burglary network)

  Query: P(B=T | J=T)

  P(B=T | J=T) = α × Σ_A P(B=T) × P(A|B=T) × P(J=T|A)
               = α × [P(B=T)×P(A=T|B=T)×P(J=T|A=T)
                    + P(B=T)×P(A=F|B=T)×P(J=T|A=F)]

  With values:
  P(B=T) = 0.001
  P(A=T|B=T) = 0.94,  P(A=F|B=T) = 0.06
  P(J=T|A=T) = 0.90,  P(J=T|A=F) = 0.05

  = α × [0.001×0.94×0.90 + 0.001×0.06×0.05]
  = α × [0.000846 + 0.000003]
  = α × 0.000849
Problem with Enumeration: For a network with n variables, each hidden variable doubles the sum — O(2n) time. For large networks this is completely infeasible. Variable Elimination solves this by reusing computations.

2. Variable Elimination Algorithm

Variable Elimination (VE) is an efficient exact inference algorithm that avoids redundant computation by summing out hidden variables one at a time using factors.

Key Idea

Instead of summing over all hidden variables at once (exponential), VE pushes sums inside products — eliminating one variable at a time and caching intermediate results as factors.

Σ_Z [ f₁(Z,X) × f₂(Z,Y) ] = f₃(X,Y)   (Z eliminated)

What is a Factor?

A factor f(X₁, ..., Xₖ) is a function that maps assignments of variables to non-negative real numbers. CPTs are factors. When we multiply and marginalize factors we produce new factors.

Two Operations on Factors

OperationSymbolMeaning
Factor Product f₁ × f₂ Multiply two factors — new factor contains all variables from both
Marginalization Σ_Z f Sum out variable Z from a factor — removes Z from the factor's scope

Variable Elimination Algorithm

  1. Start with all CPTs as initial factors
  2. Set observed evidence — fix evidence variables to observed values
  3. For each hidden variable Z (in elimination order):
    • Collect all factors that mention Z
    • Multiply them together → new factor
    • Sum out (marginalize) Z → eliminate Z from the factor
  4. Multiply all remaining factors
  5. Normalize the result to get a valid probability distribution

Worked Example — Variable Elimination

Network: B → A → J (Burglary → Alarm → JohnCalls)

Query: P(B | J=T). Hidden variable: A.

  Initial factors:
  f₁(B)     = P(B)           [prior on Burglary]
  f₂(A,B)   = P(A|B)         [CPT for Alarm]
  f₃(J,A)   = P(J|A)         [CPT for JohnCalls]

  Step 1: Set evidence J=T
  f₃ becomes f₃(A) = P(J=T|A):
    f₃(A=T) = 0.90
    f₃(A=F) = 0.05

  Step 2: Eliminate hidden variable A
    Collect factors containing A: f₂(A,B) and f₃(A)
    Multiply: f₄(A,B) = f₂(A,B) × f₃(A)

    f₄(A=T, B=T) = P(A=T|B=T) × P(J=T|A=T) = 0.94 × 0.90 = 0.846
    f₄(A=T, B=F) = P(A=T|B=F) × P(J=T|A=T) = 0.05 × 0.90 = 0.045
    f₄(A=F, B=T) = P(A=F|B=T) × P(J=T|A=F) = 0.06 × 0.05 = 0.003
    f₄(A=F, B=F) = P(A=F|B=F) × P(J=T|A=F) = 0.95 × 0.05 = 0.0475

    Marginalize out A (sum over A):
    f₅(B=T) = f₄(A=T,B=T) + f₄(A=F,B=T) = 0.846 + 0.003 = 0.849
    f₅(B=F) = f₄(A=T,B=F) + f₄(A=F,B=F) = 0.045 + 0.0475 = 0.0925

  Step 3: Multiply remaining factors
    f₆(B) = f₁(B) × f₅(B)

    f₆(B=T) = P(B=T) × f₅(B=T) = 0.001 × 0.849 = 0.000849
    f₆(B=F) = P(B=F) × f₅(B=F) = 0.999 × 0.0925 = 0.09243

  Step 4: Normalize
    Total = 0.000849 + 0.09243 = 0.093279
    P(B=T | J=T) = 0.000849 / 0.093279 ≈ 0.0091 ≈ 0.91%
    P(B=F | J=T) = 0.09243 / 0.093279 ≈ 0.9909 ≈ 99.09%

Even when John calls, there is only ~0.91% chance of burglary — because burglary is very rare (0.1% prior).

3. Complexity of Variable Elimination

PropertyValueExplanation
Time (best case) Polynomial in n For singly connected networks (polytrees)
Time (worst case) O(n × 2w) w = treewidth of the network
Space O(n × 2w) Storing intermediate factors
Complete? ✓ Yes Always finds the exact answer
Treewidth: The treewidth w of a Bayesian Network determines the cost of exact inference. Singly-connected networks (polytrees) have treewidth 1 — polynomial time. Multiply-connected networks have higher treewidth — can be exponential in the worst case.

Elimination Ordering Matters

The order in which variables are eliminated affects the size of intermediate factors and therefore the efficiency. Finding the optimal elimination ordering is NP-hard, but good heuristics exist:

  • Min-degree ordering — eliminate the variable with fewest connections first
  • Min-fill ordering — eliminate the variable that creates fewest new edges

4. Belief Propagation (Polytrees)

For singly connected networks (polytrees) — networks where there is at most one undirected path between any two nodes — exact inference can be done in linear time using the Belief Propagation (message passing) algorithm.

Network TypeAlgorithmComplexity
Singly connected (polytree) Belief Propagation O(n) — linear in number of nodes
Multiply connected Variable Elimination O(n × 2w) — exponential in treewidth
Multiply connected (large) Approximate Inference Trade accuracy for speed

GATE Tips

  • Variable Elimination = push sums inside products to avoid redundant computation.
  • Two operations: Factor Product (multiply) and Marginalization (sum out).
  • Always normalize at the end — multiply by α to get valid probabilities.
  • Elimination order affects efficiency — bad order = larger intermediate factors.
  • P(X | e) = α × Σhidden P(X, e, hidden) — basic enumeration formula.
  • Polytree (singly connected) → exact inference in linear time O(n).
  • Multiply connected networks → Variable Elimination, worst case exponential in treewidth w.
  • In GATE problems — apply VE step by step: fix evidence → eliminate hidden vars → normalize.
  • Exact inference is complete — always gives the right answer (but may be slow).
📝  Practice Questions

Q1 What does Variable Elimination do at each step?

  1. Removes a variable from the network entirely
  2. Multiplies factors containing a hidden variable, then sums it out
  3. Samples values for hidden variables randomly
  4. Applies Bayes' Theorem to each node independently
Show Answer

Answer: B — Multiply then sum out

For each hidden variable: collect all factors mentioning it, multiply them, then marginalize (sum out) that variable.

Q2 The normalizing constant α in P(X|e) = α × f(X) ensures:

  1. All probabilities are greater than 1
  2. The distribution sums to 1
  3. All variables are independent
  4. Evidence is removed from the computation
Show Answer

Answer: B — Distribution sums to 1

α = 1 / Σ_X f(X). It normalizes the unnormalized result into a valid probability distribution.

Q3 For a polytree Bayesian Network, exact inference runs in:

  1. O(2n)
  2. O(n²)
  3. O(n) — linear time
  4. O(n × 2w)
Show Answer

Answer: C — O(n) linear time

Singly connected networks (polytrees) allow Belief Propagation which runs in linear time.

Q4 Variable Elimination is better than simple enumeration because:

  1. It gives approximate answers faster
  2. It reuses intermediate computations (factors) instead of recomputing
  3. It eliminates the need for CPTs
  4. It works only on polytrees
Show Answer

Answer: B — Reuses intermediate computations

By pushing sums inside products, VE avoids repeating the same multiplications. Enumeration recomputes everything from scratch.

Q5 What determines the worst-case complexity of Variable Elimination?

  1. Number of root nodes
  2. Number of evidence variables
  3. Treewidth of the network
  4. Number of leaf nodes
Show Answer

Answer: C — Treewidth

VE complexity is O(n × 2w) where w is the treewidth. Networks with low treewidth allow efficient exact inference.
