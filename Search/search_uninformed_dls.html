Depth-Limited Search (DLS)

Uninformed Search GATE DA 📖 ~7 min read

Depth-Limited Search (DLS) is a modified version of DFS that introduces a depth limit ℓ. The algorithm will not explore any node beyond depth ℓ, preventing DFS from getting trapped in infinite paths.

Core Idea: Run DFS but stop at depth ℓ. Nodes at depth ℓ are treated as if they have no children.

How DLS Works

  1. Set a depth limit ℓ.
  2. Run DFS normally.
  3. If a node's depth exceeds ℓ → do not expand it (treat as leaf).
  4. Return solution if goal found within depth ℓ.
  5. Return failure if no solution found within ℓ.
  6. Return cutoff if the limit was reached (goal may exist deeper).

Two Types of Failure

ResultMeaning
FailureNo solution exists at all
CutoffNo solution within depth ℓ, but may exist deeper

Example

         A          ← depth 0
        / \
       B   C        ← depth 1
      / \ / \
     D  E F  G      ← depth 2

With depth limit ℓ = 1:

DLS explores: A → B → C (stops here — depth 1 reached)

D, E, F, G are never visited. If goal is G → returns cutoff.

With depth limit ℓ = 2:

DLS explores: A → B → D → E → C → F → G ✓ (Goal found!)

Properties of DLS

PropertyValueExplanation
Complete?✗ NoFails if goal is deeper than ℓ
Optimal?✗ NoMay miss better solutions outside depth ℓ
Time ComplexityO(bℓ)Explores all nodes up to depth ℓ
Space ComplexityO(b·ℓ)Same as DFS but bounded by ℓ instead of m

How to Choose the Depth Limit ℓ

Choosing a good depth limit is the main challenge of DLS:

If ℓ is...Result
Too small (ℓ < d)Goal not found → returns cutoff
Equal to dGoal found optimally
Too large (ℓ > d)Goal found but wastes time exploring extra levels
Domain Knowledge: In practice, domain knowledge helps set a good ℓ. For example, in the 8-puzzle, the diameter of the state space is known to be 31, so ℓ = 31 is a reasonable limit.

Advantages & Disadvantages

✅ Advantages

  • Solves the infinite loop problem of DFS
  • Low memory usage — O(b·ℓ)
  • Useful when the depth of the solution is known or estimated

❌ Disadvantages

  • Not complete — fails if ℓ < d
  • Not optimal — may miss better solutions
  • Choosing the right ℓ requires domain knowledge
  • Returns two types of failure (failure vs cutoff) — more complex to handle

GATE Tips

  • DLS is DFS with a depth limit ℓ — not to be confused with IDDFS.
  • DLS is neither complete nor optimal.
  • Space complexity is O(b·ℓ) — not O(b·m) like DFS (ℓ replaces m).
  • Two return values to remember: failure (no solution) vs cutoff (limit reached).
  • DLS is the building block for IDDFS — IDDFS runs DLS repeatedly with increasing ℓ.
📝  Practice Questions

Q1 DLS returns "cutoff" when:

  1. The goal does not exist
  2. The depth limit is reached without finding the goal
  3. The queue is empty
  4. The branching factor is 0
Show Answer

Answer: B

Cutoff means the search hit the depth limit — the goal may still exist at a greater depth.

Q2 DLS is complete when:

  1. ℓ ≥ d (depth limit ≥ depth of shallowest goal)
  2. The branching factor b = 1
  3. The graph has no cycles
  4. DLS is never complete
Show Answer

Answer: A

DLS finds the goal only when ℓ ≥ d. In general, ℓ is unknown so DLS is considered incomplete.

Q3 Space complexity of DLS with limit ℓ is:

  1. O(bℓ)
  2. O(b·m)
  3. O(b·ℓ)
  4. O(ℓ)
Show Answer

Answer: C — O(b·ℓ)

Same as DFS but depth bounded by ℓ instead of m.
