Depth-First Search (DFS)

Uninformed Search GATE DA 📖 ~8 min read

Depth-First Search (DFS) is an uninformed search algorithm that explores as deep as possible along each branch before backtracking. It uses a Stack (LIFO) as its data structure — or equivalently, recursion via the call stack.

Core Idea: Expand the deepest unexpanded node first. DFS dives all the way down one path before trying another.

How DFS Works

  1. Start with the initial state on the stack.
  2. Pop the top node and check if it is the goal.
  3. If yes → return the solution.
  4. If no → push all its children to the top of the stack.
  5. Repeat until goal is found or stack is empty.

Data Structure Used

Stack (LIFO) — Last In, First Out. DFS can also be implemented recursively (implicit stack).

Example

         A          ← Start
        / \
       B   C
      / \ / \
     D  E F  G      ← Goal = G

DFS Order: A → B → D → E → C → F → G

DFS goes deep into the left branch first (A→B→D), backtracks, then explores E, then the right branch (C→F→G).

Properties of DFS

Optimal?✗ NoMay find a deeper solution when a shallower one exists

Space ComplexityO(b·m)Only stores the current path — much better than BFS

Why DFS is Not Complete

DFS can enter an infinite loop if the search space has cycles or infinite depth paths. For example: 

  A → B → C → D → E → F → ... (infinite)

DFS will keep going deeper forever and never explore other branches. This can be fixed by:

  • Maintaining a visited set to avoid revisiting nodes
  • Using Depth-Limited Search (DLS) to cap the depth
Fix: In finite state spaces with a visited set, DFS becomes complete. In infinite state spaces, it remains incomplete.

Space Advantage Over BFS

DFS only needs to store the current path from root to the frontier node.

AlgorithmSpace Complexityb=10, d=10
BFSO(bd)~10 billion nodes
DFSO(b·m)~100 nodes

This massive memory advantage makes DFS preferred when memory is limited.

Advantages & Disadvantages

Advantages

  • Very low memory usage — only O(b·m) space
  • Can find solutions quickly if the goal is on a deep left branch
  • Simple recursive implementation

Disadvantages

  • Not complete — can loop forever in infinite spaces
  • Not optimal — may return a non-shortest solution
  • Worst case time O(bm) — if goal is on the far right branch

GATE Tips

  • DFS uses a Stack (LIFO). BFS uses a Queue (FIFO).
  • DFS is neither complete nor optimal in the general case.
  • Space complexity O(b·m) is DFS's main advantage over BFS.
  • DFS is complete in finite spaces if revisited states are tracked.
  • Time complexity is O(bm) — worse than BFS O(bd) if m >> d.

  1. Queue (FIFO)
  2. Priority Queue
  3. Stack (LIFO)
  4. Deque

Answer: C — Stack (LIFO)

DFS uses a LIFO stack (or recursion) to always expand the deepest node.

Q2 DFS is not complete because:

  1. It uses too much memory
  2. It can enter infinite loops in infinite depth spaces
  3. It does not explore all nodes
  4. It is slower than BFS
Show Answer

Answer: B — It can enter infinite loops

Without a depth limit or visited set, DFS may go infinitely deep on one branch.

Q3 What is the space complexity of DFS?

  1. O(bd)
  2. O(b·m)
  3. O(d)
  4. O(1)
Show Answer

Answer: B — O(b·m)

DFS only stores the current path nodes plus siblings at each level — b nodes per level × m levels.

Q4 DFS is complete when:

  1. The search space is infinite
  2. The branching factor is 1
  3. The search space is finite and revisited states are tracked
  4. All step costs are equal

Answer: C — Finite space with visited states tracked
