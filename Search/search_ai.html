Search in Artificial Intelligence

Search GATE DA 📖 Topic Overview

Search is a fundamental technique in AI for solving problems by exploring possible states to reach a goal.

Definition: Search = Process of finding a sequence of actions from Initial State → Goal State by systematically exploring the search space.

Real World Examples

  • Finding the best route from your origin to destination (Google Maps)
  • Playing games and figuring out the best next move to win (Chess, Go)
  • Solving puzzles like the 8-puzzle or Rubik's cube
  • Robot navigation through an environment

Key Concepts

TermMeaning
StateA representation of the world at a given point
Initial StateThe starting configuration of the problem
Goal StateThe desired end configuration
ActionsOperations that transition from one state to another
Path CostThe total cost of reaching a state from the start
Search SpaceThe set of all possible states reachable from the initial state
Branching Factor (b)Average number of successors per node
Depth (d)Level of the shallowest goal node

Types of Search in AI

Search algorithms are broadly divided into three categories based on their strategy:

1. Uninformed Search (Blind Search)

No domain knowledge or heuristics used. The algorithm explores the search space without any information about how close it is to the goal.

GATE Tips

  • Completeness — will the algorithm always find a solution if one exists?
  • Optimality — will it find the best (lowest cost) solution?
  • Time complexity — how many nodes are explored?
  • Space complexity — how many nodes are stored in memory?
  • These four properties are asked in almost every GATE question about search algorithms.
  • Remember: BFS uses Queue, DFS uses Stack, UCS uses Priority Queue.
  • A* = UCS + heuristic. When h(n) = 0, A* becomes UCS.
