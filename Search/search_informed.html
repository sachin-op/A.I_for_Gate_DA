Informed Search Algorithms

Informed Search GATE DA 📖 ~15 min read

Informed Search algorithms use domain-specific knowledge (heuristics) to make smarter decisions during the search process — unlike uninformed search which explores blindly. By estimating how close a node is to the goal, these algorithms prioritize promising paths and find solutions much more efficiently.

Key Difference: Uninformed search has no idea which direction the goal is. Informed search uses a heuristic function h(n) that estimates the cost from node n to the goal — guiding the search in the right direction.

Key Functions

Three functions are used to evaluate nodes in informed search:

FunctionNameMeaning
g(n) Path Cost Cumulative cost from the start node to node n (actual cost so far)
h(n) Heuristic Function Estimated cost from node n to the goal (domain knowledge)
f(n) Evaluation Function Total estimated cost — used to decide which node to expand next

Important Properties of h(n)

  • h(n) is always non-negative — h(n) ≥ 0
  • If n is a goal state → h(n) = 0
  • h(n) is state dependent — different for each node
  • h(n) cannot be derived from the problem description alone — requires domain knowledge

Best-First Search

Best-First Search is the general framework for informed search. It selects the node for expansion based on an evaluation function f(n) — the node with the best (lowest) f(n) is expanded first using a min-priority queue.

The specific algorithm depends on what f(n) is defined as:

Algorithmf(n) DefinitionStrategy
Greedy BFS f(n) = h(n) Only heuristic — fastest to goal but not optimal
A* Search f(n) = g(n) + h(n) Actual cost + heuristic — complete and optimal
UCS f(n) = g(n) Only actual cost — optimal but no heuristic guidance

1. Greedy Best-First Search

Greedy Best-First Search selects the node that appears closest to the goal based solely on the heuristic function. It ignores the cost already paid to reach the current node.

Evaluation Function

f(n) = h(n)

It is "greedy" because it always picks whichever node looks best right now — without considering whether the overall path will be optimal.

Example

Finding a route from city A to city G. Greedy BFS always moves to the city with the smallest straight-line distance to G, regardless of how far it has already traveled.

Properties of Greedy BFS

PropertyValueExplanation
Complete? ✗ No Can enter infinite loops in certain state spaces
Optimal? ✗ No Ignores g(n) — may find a longer path
Time Complexity O(bm) Worst case — explores all nodes like DFS
Space Complexity O(bm) Keeps all nodes in memory

Why Greedy BFS Fails

Consider two paths to goal G: 

  Path 1: S → A → G    actual cost = 10 + 1  = 11
  Path 2: S → B → G    actual cost = 1  + 15 = 16

If h(B) < h(A), Greedy BFS picks Path 2 (seems closer by heuristic) but Path 1 is actually cheaper. Greedy BFS is not optimal.

2. A* Search

A* Search combines the actual cost g(n) and the heuristic estimate h(n) to evaluate nodes. It is the most widely used informed search algorithm in AI.

Evaluation Function

f(n) = g(n) + h(n)

Where:

  • g(n) = actual cost from start to node n
  • h(n) = estimated cost from n to goal
  • f(n) = estimated total cost of cheapest solution through n
Key Insight: A* expands nodes in order of increasing f(n). The first time A* reaches the goal, it is guaranteed to be via the optimal path — provided h(n) is admissible.

A* vs UCS vs Greedy BFS

Algorithmf(n)CompleteOptimal
UCS g(n) ✓ ✓
Greedy BFS h(n) ✗ ✗
A* g(n) + h(n) ✓ ✓*

* A* is optimal when h(n) is admissible (tree search) or consistent (graph search).

Properties of A*

PropertyValueExplanation
Complete? ✓ Yes Will find a solution if one exists (finite branching, positive costs)
Optimal? ✓ Yes* Optimal when h(n) is admissible / consistent
Time Complexity Exponential Depends on heuristic accuracy — better h(n) = fewer nodes
Space Complexity O(bd) Keeps all frontier nodes in memory — main weakness

3. Admissibility

A heuristic h(n) is admissible if it never overestimates the true cost to reach the goal.

h(n) ≤ h*(n) for all nodes n

Where h*(n) is the true actual cost from n to the goal.

In Simple Terms

  • h(n) is always optimistic — it never says "it costs more than it actually does"
  • An admissible heuristic may underestimate the cost — that is allowed
  • An admissible heuristic must never overestimate the cost

Example — 8-Puzzle

Two common admissible heuristics for the 8-puzzle:

HeuristicDefinitionAdmissible?
h1 — Misplaced Tiles Number of tiles not in their goal position ✓ Yes — each misplaced tile needs at least 1 move
h2 — Manhattan Distance Sum of distances of tiles from their goal positions ✓ Yes — ignores blocking, so underestimates
h3 — Exact cost True number of moves needed ✓ Yes — but too expensive to compute
Why Admissibility Guarantees Optimality: If h(n) never overestimates, A* will never skip the optimal path. It will always explore the optimal path before any suboptimal one reaches the goal.

4. Consistency (Monotonicity)

A heuristic h(n) is consistent (also called monotone) if for every node n and every successor n' reached by action a with step cost c:

h(n) ≤ c(n, a, n') + h(n')

This means: the estimated cost from n is no more than the step cost to n' plus the estimated cost from n'.

Triangle Inequality

Consistency is essentially the triangle inequality — the direct path from n to the goal is never longer than going via an intermediate node n': 

  n ──── c ────→ n'
  │                \
  h(n)           h(n')
  │                  \
  └──────────────→ GOAL
h(n) ≤ c(n → n') + h(n')

Consistency vs Admissibility

AdmissibilityConsistency
Definition h(n) ≤ h*(n) — never overestimates h(n) ≤ c + h(n') — triangle inequality
Applies to Tree search Graph search (with repeated states)
Stronger? Weaker condition Stronger — consistency implies admissibility
Guarantees A* optimal in tree search A* optimal in graph search + f(n) never decreases along path
Key Rule: Consistency → Admissibility (always). Admissibility → Consistency (not always). Every consistent heuristic is admissible, but not every admissible heuristic is consistent.

5. Conditions for A* Optimality

Search TypeRequired Condition
Tree Search (no repeated state check) h(n) must be Admissible
Graph Search (with visited/closed set) h(n) must be Consistent

Why Consistent Heuristic is Needed for Graph Search

In graph search, once a node is added to the closed set it is never re-expanded. If h(n) is only admissible but not consistent, A* might close a node with a suboptimal g value and miss the optimal path. Consistency ensures f(n) values are non-decreasing along any path, so the first time a node is expanded its g(n) is already optimal.

6. Dominance — Comparing Heuristics

If two heuristics h1 and h2 are both admissible and h2(n) ≥ h1(n) for all nodes n, then h2 dominates h1.

h2 dominates h1 ⟺ h2(n) ≥ h1(n) for all n
Why Dominance Matters: A dominant heuristic is always better to use. It is closer to the true cost h*(n) so A* expands fewer nodes. Manhattan distance dominates Misplaced Tiles for the 8-puzzle — so Manhattan distance is always preferred.

Heuristic Quality

  • h(n) = 0 → worst heuristic (becomes UCS — no guidance)
  • h(n) = h*(n) → perfect heuristic (A* goes straight to goal, but too expensive to compute)
  • Between 0 and h*(n) → admissible heuristic (practical range)

Quick Reference Summary

Algorithmf(n)CompleteOptimalNotes
Greedy BFS h(n) ✗ ✗ Fast but unreliable
A* (tree) g(n) + h(n) ✓ ✓ if admissible Most used informed search
A* (graph) g(n) + h(n) ✓ ✓ if consistent Requires consistent h(n)
UCS g(n) ✓ ✓ A* with h(n) = 0

GATE Tips

  • f(n) = g(n) + h(n) — memorize this formula for A*.
  • Greedy BFS uses only h(n) — not optimal, not complete.
  • UCS is A* with h(n) = 0.
  • Admissible = never overestimates. h(n) ≤ h*(n).
  • Consistent = triangle inequality. h(n) ≤ c + h(n').
  • Consistency implies admissibility — not the other way around.
  • For tree search → admissibility is enough for optimality.
  • For graph search → need consistency for optimality.
  • Manhattan Distance dominates Misplaced Tiles for 8-puzzle — fewer nodes expanded.
  • A perfect heuristic h(n) = h*(n) makes A* expand only nodes on the optimal path.
📝  Practice Questions

Q1 What is the evaluation function used by A* search?

  1. f(n) = h(n)
  2. f(n) = g(n)
  3. f(n) = g(n) + h(n)
  4. f(n) = g(n) × h(n)
Show Answer

Answer: C — f(n) = g(n) + h(n)

g(n) = cost from start to n. h(n) = estimated cost from n to goal. f(n) = total estimated cost.

Q2 A heuristic is admissible if:

  1. h(n) ≥ h*(n) for all n
  2. h(n) ≤ h*(n) for all n
  3. h(n) = g(n) for all n
  4. h(n) = 0 for all n
Show Answer

Answer: B — h(n) ≤ h*(n)

Admissible means never overestimating — the heuristic is always ≤ the true cost h*(n).

Q3 Which condition must h(n) satisfy for A* graph search to be optimal?

  1. Admissibility only
  2. Consistency only
  3. Both admissibility and consistency
  4. Neither — A* is always optimal
Show Answer

Answer: B — Consistency

Graph search needs consistency. Tree search only needs admissibility. Consistency implies admissibility so B is sufficient.

Q4 Greedy Best-First Search uses:

  1. f(n) = g(n) + h(n)
  2. f(n) = g(n)
  3. f(n) = h(n)
  4. f(n) = h(n) - g(n)
Show Answer

Answer: C — f(n) = h(n)

Greedy BFS only uses the heuristic — it ignores the actual cost g(n) already paid.

Q5 If h2(n) ≥ h1(n) for all n and both are admissible, then:

  1. h1 dominates h2
  2. h2 dominates h1
  3. They are equally good
  4. Neither dominates
Show Answer

Answer: B — h2 dominates h1

h2 is closer to the true cost h*(n), so A* expands fewer nodes with h2.

Q6 The consistency condition states:

  1. h(n) ≤ h*(n)
  2. h(n) ≤ c(n, n') + h(n')
  3. h(n) = g(n) + h(n')
  4. h(n) ≥ c(n, n') + h(n')
Show Answer

Answer: B — h(n) ≤ c(n, n') + h(n')

This is the triangle inequality — the estimated cost from n is no more than the step cost to n' plus the estimated cost from n'.

Q7 UCS is a special case of A* when:

  1. g(n) = 0
  2. h(n) = 0
  3. f(n) = h(n)
  4. g(n) = h(n)
Show Answer

Answer: B — h(n) = 0

When h(n) = 0, f(n) = g(n) + 0 = g(n) — which is exactly what UCS uses.

Q8 Which statement about consistency and admissibility is TRUE?

  1. Admissibility implies consistency
  2. Consistency implies admissibility
  3. They are equivalent conditions
  4. Neither implies the other
Show Answer

Answer: B — Consistency implies admissibility

Consistency is the stronger condition. Every consistent heuristic is also admissible, but not every admissible heuristic is consistent.
