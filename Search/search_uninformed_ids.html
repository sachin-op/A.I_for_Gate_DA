Iterative Deepening DFS (IDDFS)

Uninformed Search GATE DA 📖 ~9 min read

Iterative Deepening Depth-First Search (IDDFS) combines the best properties of BFS and DFS. It runs DLS repeatedly with an increasing depth limit — starting from ℓ = 0, then ℓ = 1, then ℓ = 2, and so on — until the goal is found.

Core Idea: Run DLS with ℓ = 0, 1, 2, 3, ... until goal found. Gets BFS completeness + optimality with DFS memory efficiency.

How IDDFS Works

  1. Set depth limit ℓ = 0.
  2. Run DLS with current ℓ.
  3. If solution found → return it.
  4. If cutoff (limit reached, goal not found) → increment ℓ by 1 and repeat.
  5. If failure (no solution exists at any depth) → return failure.

Pseudocode

function IDDFS(problem):
  for depth = 0, 1, 2, 3, ... :
    result = DLS(problem, depth)
    if result ≠ cutoff:
      return result

Is Repeated Work a Problem?

IDDFS re-visits nodes in earlier iterations (e.g. level 0 and 1 nodes are visited again in iteration 3). This seems wasteful, but the overhead is small:

LevelTimes VisitedNodes at LevelTotal Cost
0 (root)d+1 times1d+1
1d timesbd·b
2d-1 timesb²(d-1)·b²
d1 timebdbd

Total nodes ≈ O(bd) — dominated by the last level.

Key Insight: The repeated work at upper levels is negligible because the number of nodes grows exponentially. The bottom level (bd) dominates all previous iterations combined. IDDFS is only ~10-15% slower than BFS in practice.

IDDFS is the preferred uninformed search algorithm in practice when the search depth is unknown.

Advantages & Disadvantages

✅ Advantages

  • Complete and optimal like BFS (equal step costs)
  • Low memory like DFS — only O(b·d) space
  • No need to know the depth in advance
  • Best choice when search depth is unknown

❌ Disadvantages

  • Revisits upper-level nodes multiple times (small overhead in practice)
  • Not optimal for unequal step costs — use UCS instead

GATE Tips

  • IDDFS = DLS called repeatedly with ℓ = 0, 1, 2, ...
  • IDDFS is complete and optimal (equal costs) — same as BFS.
  • Space complexity is O(b·d) — much better than BFS O(bd).
  • Time complexity is O(bd) — same as BFS asymptotically.
  • IDDFS is the preferred algorithm when memory is limited and depth is unknown.
  • Repeated work overhead is negligible — lower levels dominate.
