Uninformed Search Algorithms (Blind Search)

Search GATE DA 📖 ~10 min read

Uninformed Search (also called Blind Search) is a class of search algorithms in Artificial Intelligence that explore the search space without using any domain-specific knowledge or heuristics about the goal.

The algorithm only knows the initial state, the goal state, and the actions available — it has no idea whether one path is "better" or "closer" than another. It simply explores systematically until it finds the goal.

Key Difference from Informed Search: Uninformed search has no heuristic function h(n). It treats all nodes equally and explores blindly. Informed search (like A*) uses h(n) to guide exploration toward the goal more efficiently.
⚠
Limitation: These algorithms can be very inefficient for large search spaces because they cannot "see" whether they are getting closer to the goal.

Algorithms in Uninformed Search

There are five main uninformed search algorithms, each with its own strategy for exploring the search space:

01 Breadth-First Search Explores all nodes level by level. Guaranteed to find the shallowest goal.
Complete ✓ Optimal ✓ Time: O(bd) Space: O(bd)
→ 02 Depth-First Search Explores as deep as possible before backtracking. Low memory usage.
Not Complete Not Optimal Time: O(bm) Space: O(b·m)
→ 03 Depth-Limited Search DFS with a depth limit ℓ. Prevents infinite loops in infinite spaces.
Not Complete Not Optimal Time: O(bℓ) Space: O(b·ℓ)
→ 04 Iterative Deepening DFS Runs DLS repeatedly with increasing depth. Best of BFS + DFS.
Complete ✓ Optimal ✓ Time: O(bd) Space: O(b·d)
→ 05 Uniform Cost Search Expands the node with the lowest path cost g(n). Optimal for weighted paths.
Complete ✓ Optimal ✓ Time: O(b1+⌊C*/ε⌋) Space: O(b1+⌊C*/ε⌋)
→ 06 Bidirectional Search Two simultaneous searches meet in the middle. Dramatic reduction in nodes explored.
Complete ✓ Optimal ✓ Time: O(bd/2) Space: O(bd/2)

Comparison Table

Quick reference for all five algorithms — very useful for GATE MCQs:

Algorithm Complete? Optimal? Time Space
BFS ✓ Yes ✓ Yes* O(bd) O(bd)
DFS ✗ No ✗ No O(bm) O(b·m)
DLS ✗ No ✗ No O(bℓ) O(b·ℓ)
IDDFS ✓ Yes ✓ Yes* O(bd) O(b·d)
UCS ✓ Yes ✓ Yes O(b1+⌊C*/ε⌋) O(b1+⌊C*/ε⌋)

* Optimal when all step costs are equal  ·  b = branching factor  ·  d = depth of shallowest goal  ·  m = max depth  ·  ℓ = depth limit  ·  C* = optimal cost  ·  ε = min step cost

When to Use Which?

SituationBest AlgorithmWhy
Shallowest solution needed, memory not a concern BFS Guaranteed shortest path (unweighted)
Memory is very limited DFS Only O(b·m) space — much better than BFS
Search space is infinite, need to avoid loops DLS Sets a hard depth limit to prevent infinite traversal
Need BFS optimality with DFS memory IDDFS Best of both worlds — preferred in practice
Edge costs are different (weighted graph) UCS Finds minimum cost path, not just minimum depth
