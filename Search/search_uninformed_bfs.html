Breadth-First Search (BFS)

Uninformed Search GATE DA 📖 ~8 min read

Breadth-First Search (BFS) is an uninformed search algorithm that explores all nodes at the current depth level before moving to the next level. It uses a FIFO queue as its data structure.

Core Idea: Expand the shallowest unexpanded node first. BFS guarantees finding the goal at the minimum depth (shallowest path).

How BFS Works

  1. Start with the initial state in the queue.
  2. Dequeue the front node and check if it is the goal.
  3. If yes → return the solution.
  4. If no → expand the node and add all its children to the back of the queue.
  5. Repeat until goal is found or queue is empty.

Data Structure Used

Queue (FIFO) — First In, First Out. Nodes added to the back, removed from the front.

Example

Consider a tree with branching factor b = 2:

         A          ← Level 0 (Start)
        / \
       B   C        ← Level 1
      / \ / \
     D  E F  G      ← Level 2 (Goal = G)

BFS Order: A → B → C → D → E → F → G

BFS visits level by level, so it finds G after visiting all nodes at level 1 first.

Properties of BFS

PropertyValueExplanation
Complete?✓ YesWill always find a solution if one exists (finite branching factor)
Optimal?✓ Yes*Finds shallowest goal — optimal when all step costs are equal

Space ComplexityO(bd)Keeps all frontier nodes in memory — major drawback

Complexity Analysis

With branching factor b and goal at depth d:

LevelNodes Generated
01
1b
2b²
3b³
dbd

Total nodes = 1 + b + b² + ... + bd = O(bd)

Memory Problem: BFS stores all nodes at the current frontier. For b=10, d=10 → over 10 billion nodes in memory. This makes BFS impractical for deep search spaces.

Advantages & Disadvantages

Advantages

  • Always finds the shallowest (shortest path) solution
  • Complete — will not miss a solution if it exists
  • Simple to implement using a queue

Disadvantages

  • High memory usage — stores all frontier nodes (O(bd))
  • Not optimal when step costs are unequal
  • Slow for deep goal states — explores all shallower nodes first

GATE Tips

  • BFS is complete and optimal only when step costs are equal.
  • For weighted graphs, use UCS — BFS may not find the optimal cost path.
  • Space complexity O(bd) is BFS's biggest weakness compared to DFS O(b·m).
  • IDDFS gives BFS-like optimality with DFS-like memory — preferred in practice.
  • BFS uses a Queue (FIFO). DFS uses a Stack (LIFO).

  1. Stack
  2. Priority Queue
  3. Queue (FIFO)
  4. Linked List

Answer: C — Queue (FIFO)

BFS uses a FIFO queue to ensure nodes are explored level by level.

Q2 BFS is optimal when:

  1. The graph is directed
  2. All step costs are equal
  3. The branching factor is large
  4. The depth is large
Show Answer

Answer: B — All step costs are equal

BFS finds the shallowest goal, which is optimal only when all edges have equal cost.
